The 542 events data was loaded into Excel; the data was de-duplicated for (user_id, step) pair and fixed funnel order was maintained instead of using the default groupby ordering. The number of unique users and the conversion rate from stage to stage were computed. There were 146 users having a sequence gap logged in the data as an issue of data quality. The biggest drop-off was observed in details_filled to email_verified stages (45.8% drop-off in terms of conversion rate), though signup_started to details_filled had more drop-offs in numbers (54 vs. 44).
